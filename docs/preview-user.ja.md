# 動作確認とVRM保存

「動作確認」は、構造・MToon・テクスチャ・部位別物理応答の自動検査が済んだVRMを目視確認する画面です。モデル情報が未登録でも自動表示し、物理ONでデフォルト歩行を自動再生します。見た目の良し悪しはユーザーが判断します。

- 左の「デフォルト（歩行）」と右の「モーションを読み込む（VRMA）」でモーションを選びます。読み込み済みモーションは画面を開いている間、デフォルトと切り替えられます。「変更」で置き換えます。
- 「一時停止」はアニメーションだけを止めます。モデルをマウスでつかんで動かすと、物理による揺れを確認できます。背景のドラッグではカメラを操作します。
- 「元の姿勢」「骨を表示」を使えます。「物理をリセット」はモデルの位置とポーズを保って揺れを初期化します。
- 「VRMを書き出す」でモデル名・作者名・利用条件を確認し、「登録して書き出す」で情報の保存とダウンロードまで進みます。保存した情報は次回も使えます。形状・材質・揺れものは確認した内容を保持します。キャンセルしても動作確認を続けられます。エージェントへの依頼は不要です。

独立したプレビューと表示専用のトゥーン調整、時間スライダー、確認画像の保存、骨対応の編集は廃止しました。MToonは完成VRM自身の材質を使います。ポーズ・確認中の位置・読み込んだVRMAはVRM保存内容へ反映しません。再読込後はデフォルト歩行で開きます。

ローカル版では作業用Blendからの準備を自動で行います。準備や検査に失敗した場合は理由を表示し、成功した扱いにしません。詳しくは[通常の制作手順](tutorial.ja.md)を参照してください。
