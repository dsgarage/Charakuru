# 동작 확인과 VRM 저장

[튜토리얼](tutorial.ko.md) · [日本語](preview-user.ja.md)

‘동작 확인’은 구조·MToon·텍스처·부위별 물리 응답의 자동 검사를 통과한 완성 VRM을 눈으로 확인하는 화면입니다. 물리 ON으로 기본 걷기를 자동 재생합니다. 외관의 평가는 사용자가 합니다.

- 왼쪽 **기본 (걷기)**와 오른쪽 **모션 불러오기 (VRMA)**로 모션을 선택합니다. 현재 화면에서는 기본 걷기와 불러온 모션을 전환할 수 있습니다. **변경**으로 다른 파일을 선택합니다.
- **일시정지**는 애니메이션만 멈춥니다. 모델을 잡아 움직이면 물리 흔들림을 확인할 수 있고 배경을 드래그하면 카메라를 조작합니다.
- **원래 자세**, **스켈레톤 표시**, **물리 초기화**를 사용할 수 있습니다. 물리 초기화는 위치와 포즈를 유지하면서 흔들림을 초기화합니다.
- **VRM 내보내기**에서 모델 이름·작성자·이용 조건을 확인하고 **정보 저장 후 내보내기**로 정보를 저장하며 다운로드합니다. 형상·재질·흔들림은 확인한 내용을 유지합니다. 취소해도 동작 확인을 계속할 수 있으며 에이전트 요청은 필요하지 않습니다.

MToon은 완성 VRM의 재질을 사용합니다. 독립 미리보기·표시 전용 툰 조정·시간 슬라이더·확인 이미지 저장·본 대응 편집은 현재 동작 확인 화면에 없습니다. 확인용 위치·포즈·불러온 VRMA는 VRM 저장에 반영하지 않습니다. 새로고침하면 기본 걷기로 돌아갑니다.

로컬판은 작업 Blend에서 VRM 준비를 자동으로 진행합니다. 준비·검사에 실패하면 이유를 표시하며 성공으로 처리하지 않습니다.
