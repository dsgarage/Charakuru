# きゃらくるのはじめ方

[English](getting-started.md) · [한국어](tutorial.ko.md) · [概要](../README.ja.md)

## キットを用意する

[Releases](https://github.com/nanocle/Charakuru/releases)の専用配布ZIPを使います。GitHubの自動生成Source codeアーカイブとは別です。書込み可能な任意のフォルダへ展開し、ファイルをまとめて保管してください。

Node.js 22以上とデスクトップのChromium系ブラウザを用意します。Codexで展開したフォルダを開き、ルートの `AGENTS.md` を読んで起動を手伝うよう依頼してください。このファイルにキット全体の準備をまとめ、制作工程の9つのSkillsで制作を進めます。

エージェントがローカルアプリを起動します。自分で起動する場合は、展開したフォルダで `npm start` を実行し、表示されたローカルURLを開きます。通常起動に `npm install` は不要です。

素材やモデルの制作には、対応する画像生成機能、Tripoへログインしたブラウザ、Blender、Blender MCP、VRM Add-on for Blenderも必要です。それぞれのアカウント・利用条件・料金は別です。

## 確認地点を進める

元絵を登録し、8枚の画像確認、頭・体の候補決定、頭身調整、動作確認を行います。アプリの「次へ」の依頼文をエージェントのチャットへコピーし、ZIP内の現時点のガイドに沿って進めてください。

正本の `.charakit` はアプリが保存します。同じ展開場所から再起動すると、前回の保存状態を開きます。右上の「保存」も使えます。制作フォルダを持ち運ぶ場合は、必要なBlend、VRMなどの成果物も保管してください。

画像制作ではバランス調整用の全身三面図も用意します。動作確認では完成予定のVRMを表示し、モーションと揺れものの物理を確認できます。一時停止中はモデルをドラッグして揺れを確認し、「VRMを書き出す」でモデル情報を設定して保存します。独立したプレビュー・仕上げタブは廃止しました。画面ごとの手順は[チュートリアル](tutorial.ja.md)をご覧ください。
