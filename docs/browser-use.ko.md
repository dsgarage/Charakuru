# 제작에 사용할 브라우저 선택과 재사용

[日本語](browser-use.md)

Tripo와 아바타 키트를 열 때 사용자의 기존 데스크톱 브라우저·창·프로필을 재사용하세요. 브라우저 조작 도구의 절차를 읽고 다음 순서를 따릅니다.

1. 사용자가 브라우저나 탭을 지정했다면 사용합니다. 지정하지 않았다면 열린 브라우저와 탭을 확인하여 Tripo에 로그인된 브라우저 또는 앱이 열린 브라우저를 우선합니다.
2. 페이지 탭이 있으면 재사용합니다. 요청의 URL과 포트를 확인하고 조작을 위해 같은 앱의 탭을 추가하거나 다시 열거나 새로고침하지 마세요.
3. 탭이 없으면 기존 브라우저의 같은 창·프로필에 추가하세요. 다른 작업 탭의 내용을 덮어쓰지 마세요.
4. 열린 브라우저가 없음을 확인한 경우에만 데스크톱 브라우저를 새로 시작합니다. 사용자의 지정이 없으면 Chrome 계열을 사용합니다. 제작용 별도 자동화 프로필이나 헤드리스 브라우저를 만들지 마세요.
5. 목록 조회나 연결 실패를 ‘브라우저가 열려 있지 않음’으로 판단하지 마세요. 기존 브라우저 연결이나 대상 탭 지정을 안내하세요. 연결 실패를 이유로 Codex 내장 브라우저나 다른 세션으로 자동 전환하지 마세요.

기존 로그인 상태에는 브라우저 연결을 사용하세요. Codex 내장 브라우저는 별도 상태이므로 대체로 사용하지 않습니다. 연결 설정은 [공식 안내](https://learn.chatgpt.com/docs/chrome-extension)를 참조합니다.

Tripo Studio 모델 다운로드는 배포 ZIP에 포함된 `skills/tripo-studio-download/SKILL.md`를 사용합니다. 일반 Export를 조작하여 같은 컴퓨터의 다운로드 파일을 확인하세요. Studio Export에 다운로드 이벤트 대기·저장 헬퍼를 함께 사용하지 마세요.

## 아바타 키트 요청을 받았을 때

요청의 `agent-session.mjs begin`을 실행하고 요청을 보낸 탭을 열어 둔 채 최신 상태 저장을 기다리세요. 이 명령을 위해 다른 탭을 열 필요는 없습니다. 완료 알림의 자동 불러오기를 사용합니다.

사용자가 앱을 새로고침·다시 열었거나 요청이 만료되었다면 현재 화면에서 내용을 확인하고 요청문을 다시 복사하도록 안내하세요. 이전 요청으로 제작을 시작하지 마세요.
