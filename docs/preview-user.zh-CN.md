# 动作确认与 VRM 保存

[教程](tutorial.zh-CN.md) · [日本語](preview-user.ja.md) · [한국어](preview-user.ko.md)

“动作确认”用于目视检查已通过结构、MToon、纹理及各部位物理响应自动检查的 VRM。即使模型信息尚未填写，也会自动显示，默认行走与物理开启。外观好坏由用户判断。

- 左侧“默认（行走）”和右侧“载入动作（VRMA）”用于选择动作。已载入动作可在页面打开期间与默认动作切换，点击“更换”替换。
- “暂停”仅停止动画。用鼠标抓住模型移动可观察摆动，拖动背景则操作相机。
- 可使用“静止姿势”和“显示骨架”。“重置物理”保持模型位置与姿势，仅重置摆动。
- 点击“导出 VRM”，确认名称、作者与使用条件，再点“保存信息并导出”完成保存和下载。信息随项目保留，形状、材质和摆动保持已确认结果。取消不妨碍继续预览，不需要 Agent 请求。

预览中的位置、姿势和临时 VRMA 不写入最终 VRM，重新载入后恢复默认行走。MToon 使用完成 VRM 自身材质。旧版独立预览、仅显示用的卡通设置、时间滑块、预览截图保存和骨骼映射编辑已不属于当前动作确认流程。

本地应用自动从工作 Blend 准备模型。准备或检查失败会显示原因，不会作为成功处理。完成物保存在项目 `exports` 文件夹，包括 `avatar.vrm` 与可编辑 `avatar.blend`。
