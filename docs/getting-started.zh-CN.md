# 开始使用 Charakuru

[README](../README.zh-CN.md) · [完整教程](tutorial.zh-CN.md) · [English](tutorial.md) · [日本語](tutorial.ja.md) · [한국어](tutorial.ko.md)

从 [Releases](https://github.com/nanocle/Charakuru/releases) 下载专用套件 ZIP，解压到可写文件夹，不要用 GitHub 自动生成的 Source code ZIP 代替。安装 Node.js 22 或更新版本，准备桌面 Chromium 浏览器。

在 Codex 中打开解压目录，请 Agent 阅读根目录 `AGENTS.md`，并用简体中文帮助启动。也可自行执行 `npm start`，打开显示的本地地址；无需 `npm install`。在设置中选择“简体中文”。

制作还需图片生成、已登录 Tripo 的可控浏览器、Blender 5.2、Blender MCP、VRM Add-on。外部账户、条款和费用分别管理。

依次添加原图、确认八张部位图与三视图、选择头部和身体候选、调整比例、确认动作。每次复制应用请求到 Agent 聊天并发送，保持应用标签页打开。Agent 开始时保存同一 `project.charakit`，完成后应用自动载入结果。

动作确认中查看最终 VRM 的动画与物理。暂停后可拖动模型测试摆动。点击“导出 VRM”，填写模型信息并保存，无需再发 Agent 请求。迁移时保留整个项目文件夹，包括 Blend、VRM 和其他输出。

屏幕操作见[完整教程](tutorial.zh-CN.md)，问题报告见[报告指南](../CONTRIBUTING.md)。使用前阅读[使用条款说明](license.zh-CN.md)与正式 [LICENSE](../LICENSE)。
