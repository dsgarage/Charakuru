# 浏览器选择、复用与 Tripo 语言

[English](browser-use.md) · [한국어](browser-use.ko.md) · [教程](tutorial.zh-CN.md)

打开套件或 Tripo 时，复用用户现有桌面浏览器、窗口和个人资料，以保留登录状态。先阅读当前浏览器工具的连接说明。

1. 用户指定浏览器或标签页时使用该目标。未指定时，检查已打开浏览器与标签，优先选择已登录 Tripo 或打开套件的浏览器。
2. 目标页面已存在则复用。检查请求 URL 与端口，不要为执行开始命令额外打开、重新打开或刷新同一应用。
3. 目标标签不存在时，在现有浏览器同一窗口与个人资料下新增，不覆盖其他任务标签。
4. 仅在确认没有浏览器打开时才新建浏览器。未指定时使用 Chromium 桌面浏览器，不为制作建立另一自动化个人资料或无头会话。
5. 列表查询或连接失败不等于没有浏览器。请指导连接现有浏览器或指定目标标签，不自动切换到 Codex 内置浏览器或另一会话。

需要连接扩展时参见[官方连接说明](https://learn.chatgpt.com/docs/chrome-extension)。

## Tripo 的显示语言

从 `https://studio.tripo3d.ai/workspace/generate` 等不带 `/ja/` 的地址进入，避免将日语资料中的语言路径直接用于所有用户。优先保留已登录标签，并在 Tripo 自身设置中选择简体中文；若当前服务不支持，使用 English 并用简体中文说明。不要猜测不存在的本地化 URL，不因参考资料是日语就切换到日语。

Agent 的说明、进度、完成和失败报告仍使用简体中文，除非用户另行指定。命令、路径、ID、模型名和用户备注保持原文。

下载 Tripo Studio 模型时使用 `tripo-studio-download`，操作普通 Export，并确认本机实际保存的文件。不要对 Studio Export 混用下载事件等待或另一个会话的保存助手。

## 收到套件请求后

先执行请求中的 `agent-session.mjs begin`，保持发出请求的应用标签打开，等待最新状态保存，不必为命令新开一个套件标签。使用完成通知自动载入结果。若用户刷新、重新打开应用或请求失效，先确认当前内容，再复制新请求，不使用过期输入继续制作。
