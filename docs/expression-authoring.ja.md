# モデルを見て合わせ、表情を綺麗に仕上げる

エージェントが目・口・眉の対応を画像とモデルで決め、同梱スクリプトでフィット・転送し、必要な局所をBlenderで整える任意工程です。8眼・10口・5眉を別キーとして扱えます。依頼した一部だけの制作も可能です。全表情の機械的な保存が目的ではなく、そのモデルらしい自然で可愛い仕上がりを比較して作ります。

## 作り方

目は皮膚だけの簡略マスクへ目頭・目尻・上下の8点を合わせ、別のまつ毛等を明示指定して転送します。口は本来の穴を確かめ、上下の口縁を別々に対応させます。近接した唇の取り違えを避け、接続する周辺皮膚へ変形を配ります。眉は独立部品から転送し、必要な場合だけ眉の周囲も追従させます。まばたきと眉の感情を分けて調整できます。

正面・左右45度・横、途中強度、目口眉の組合せを見ます。必要に応じて瞼の複数列への変形分散、目尻、眉の印象、曲面の奥行き、口全体の弧を整えます。Computer Useの編集と補助スクリプトを使い分けます。元モデルのまつ毛の尖りなどと、転送で生じた崩れを区別し、鑑賞時に自然で可愛く仕上がっていれば完了します。追加の画面編集は必須工程ではありません。

## キットから使う

`制作Skill`が入口です。リギングの次にある「表情制作」タブの右上から制作を依頼し、依頼文をコピーしてエージェントへ渡します。表情がないモデルでは調整欄が無効になり、制作または読み込み後に使えます。

「表情を読み込む」はVRM 0.x／1.0、表情を含むGLB、キャラキットに対応します。キャラキットを選ぶとプロジェクト全体を開いて再開します。制作済みGLBや確認用VRMが同梱されていれば自動で表情を一覧にします。独自の表情名も保持します。

表情を選んで強度と最小値・最大値を設定し、複数の表情を組み合わせて確認できます。VRM表情の範囲は0〜1、独自の変形は-10〜10です。選択・強度・範囲・読み込んだ元モデルはキャラキットへ保存されます。これらはプレビューの調整値で、元VRMを書き換えません。顔の形そのものの修正はエージェントへ依頼するか、制作済みデータの表情ラボからBlenderで行います。

> 同梱のavatar-expression-authoringを使い、このモデルに目・口・眉の表情を作ってください。通常顔の印象を保ちながら自然で可愛く仕上げ、多方向と中間強度の比較を見せてください。

Blender 5.2以降を使います。MToon表示はVRM Add-onと表示用の材質コピーを使い、カラーマネージメントはStandardです。構造確認にはソリッド／ワイヤーを使います。目標・現在・修正前を重ねられる比較画面、撮影・保存ヘルパー、必要な時だけ読む診断資料を同梱します。

同じ制作フォルダーのcurrent.blendから再開できます。原本、Basis、既存キー、UV、面、材質を保持します。口内やテクスチャは新造しません。結果は任意のBlend・GLB・比較画像として同じプロジェクトへ返し、既存VRMは変更しません。形状に応じた目視調整は必要で、どのモデルでも無修正で完成する保証ではありません。
